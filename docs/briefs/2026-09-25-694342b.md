## What to watch

- **#113 (open, being worked in parallel — do not touch tests)**: two timing-dependent tests failed once each under CI load — `test_a_cancel_from_another_process_stops_the_run` on `main` at the #86 merge (Python 3.12), and `test_the_screen_follows_a_job_while_it_runs` on the #112 branch (passed on rerun and 5/5 locally). - **`make test-fast` and `make check` can diverge**: a new slow test that nobody marks `slow` just always runs (safe), but a regression only a *marked*-slow test catches (the SQLite hammer, the full 25-theme sweep) is invisible to an agent iterating on `test-fast` alone — the full suite is one command away and is required once before a PR, per `CLAUDE.md`.
- **The PDF engine's first load now lands inside a request** (`create_job`, or the document step) rather than at startup: the ~4 s import is paid by whichever caller is first, in a thread, which is fine for one process but is a latency a concurrent first PDF request will feel while it imports (0108's own consequences call this out; not yet observed as a report).
- **`answer_invents_no_file` is the one guard against a generator claiming a file the run does not have** — falsified 7 ways in #114 (the list dropped from either prompt, the note always saying "none", the example bullet restored, no exemption for a request-named kind), but it is still one check on one prompt family; a differently-worded invention it has not seen would pass silently.
